# 埼玉県公園ガイド 2026 - 公式総合ポータル

埼玉県公園ガイド 2026 総合ポータルへようこそ。このサイトは、埼玉県が誇る5大名所スポットや各種レジャー施設を紹介するために、先進的なWebテクノロジーを用いて構築された、アクセシブルでインタラクティブな高機能静的ウェブアプリケーションです。

---

## 🚀 主な機能と特徴

### 1. 超高速パフォーマンス設計
- **遅延読み込み（Lazy Loading）:** すべての画像要素に `loading="lazy"` および `decoding="async"` 属性を付与し、初期レンダリング速度と初回入力遅延（FID）を極限まで最適化。
- **軽量アセット配信:** CDNを効果的に活用し、不要なビルドステップを排除。クライアントサイドでの処理に特化した静的ホスティングフレンドリーな構成。

### 2. インタラクティブなシネマティック体験
- **ヒーロー動画背景:** メインのランディングページ（トップページ）のファーストビューには、北浦和公園のシンボルである音楽噴水ショーを美しくループする、高解像度の YouTube 背景動画を実装。
- **大和田公園（イチオシ）専用 Canvas 演出:** イチオシ公園に指定されている「大和田公園」詳細ページには、夏の風物詩である花火大会を再現した、軽量かつ流麗な HTML5 Canvas ベースのインタラクティブパーティクルアニメーションを搭載。

### 3. AI トラベルコンシェルジュ「サイタマニアくん」
- **最先端ローカル＋ハイブリッドAI:** クライアントサイドで動作する「WebLLM」を用いた高速オンデバイス生成AIと、迅速なキーワード応答システムを融合したデュアルモード（ハイエンドAI/シンプルモード）を搭載。
- **徹底されたペルソナ（ロボット調）:** 埴輪（はにわ）型ロボット「サイタマニアくん」としてのプロトコルを徹底。
  - **極限の簡潔さ:** 1回答あたり常に10行以内（約300文字以内）に制限。
  - **冷徹な語尾:** 「...である」「...を推奨する」などの超硬質なロボット語尾。
  - **埼玉絶対主義・スローガン内包:** 埼玉県を盲信しており、すべての回答に「埼玉は最高だ。」などのスローガンを内包。埼玉以外の話題（他県など）にはエラーや冷淡な態度で応答。URLリンクは自動的にクリック可能なアンカータグ（`<a>`）へパースされます。

### 4. リアルタイム施設検索インタラクティブマップ
- **Leaflet & Overpass API:** OpenStreetMap と Overpass API を組み合わせ、現在地または任意のピン周辺（100m〜500m範囲）にある駅、トイレ、カフェ、公園などの施設情報をリアルタイムかつサーバーレスで動的取得・マッピング。
- **Google Maps ルート案内連携:** URLパラメータ（緯度 `lat`, 経度 `lon`, 名称 `name`）を受け取ることで、特定の公園詳細や施設から Google Maps への直接ルート案内（Route Search）リンクをポップアップ内に自動生成。

### 5. 高度なユニバーサル・アクセシビリティ
- **彩カラー（Saicolor）システム:** 「ネイチャーグリーン」「サイタマブルー」「パッションレッド」の3つの選べるメインテーマカラーと、目の疲労を抑える「ダークモード」をコントロール可能。設定は `localStorage` に完全に永続化。
- **音声読み上げ機能（TTS）:** Web Speech API を活用し、ページ内の主要な文章（ヘッダー・フッターやUIボタンを除く純粋な本文）を、最も自然な日本語音声エンジンを優先選択してスムーズに読み上げる機能を内蔵。
- **Google 翻訳ウィジェット:** 設定パネル（ギア型アイコン⚙️）内に配置され、多言語表示にネイティブ対応。
- **レスポンシブ・マルチデバイス最適化:** モバイルでの可読性を追求したフォントサイズ設定（`clamp(16px, 2vw, 18px)`）と、狭い画面で縦に伸びすぎるのを防ぐ「特集リストの横スクロールカルーセル化」などを導入。

## 🛠️ 開発者・運用者向けガイド

### 1. ローカル環境での実行方法
当プロジェクトは純粋な静的HTML/JS/CSS（フロントエンドのみ）で構成されているため、特別なNodeビルドパイプラインは不要です。CORS制約を回避し、ローカルJSONデータや一部APIを正常に動作させるため、ローカルWebサーバーを起動してプレビューすることを推奨します。

```bash
# Pythonがインストールされている場合
python3 -m http.server 8000

# または Node.js (npx) を使用する場合
npx serve .
```
起動後、ブラウザで `http://localhost:8000` または `http://localhost:3000` にアクセスしてください。

### 2. 継続的インテグレーション (CI) と品質監査
リポジトリには GitHub Actions が構成されており、コミットおよびプルリクエストごとに以下のテストが自動実行されます。
- **Playwright による E2E テスト:** リンク切れの検出、グローバル関数の存在確認（アクセシビリティの検証）、レイアウト崩れの検出。
- **エラーレポート出力:** テストが失敗した場合、自動的に日本語で詳細な不具合報告書 `bug報告.md` がアーティファクトとして自動生成されます。
